# 集群编队仿真示例

本目录提供一个**纯 Python 标准库**的无人机集群编队仿真骨架 `swarm_boids.py`。
它用 Boids（分离 / 对齐 / 聚合）模型驱动一个三维点质量集群，并加入最大速度、
最大加速度等简单的无人机运动约束。无需安装 numpy、matplotlib 等第三方依赖即可运行，
适合作为后续集群控制研究的最小实验起点。

## 快速开始

在仓库根目录执行：

```bash
python3 examples/swarm_boids.py --n 10 --steps 40
```

输出示例（每 20 步输出一行统计）：

脚本默认使用固定随机种子，因此同一组参数的结果可复现。仿真过程中会断言位置与速度不出现 NaN / inf，一旦数值发散会立刻抛出 `AssertionError`。

## 参数说明

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `--n` | `20` | 集群个体数量，至少为 2（否则无法计算最近邻距离） |
| `--steps` | `100` | 仿真步数，每步推进 `DT = 0.1` 秒 |
| `--seed` | `42` | 随机种子；固定种子保证初始位置、初速度与结果可复现 |

除命令行参数外，脚本顶部的模块常量可以直接调整：分离 / 邻居半径、三条规则的权重、最大速度 `MAX_SPEED`、最大加速度 `MAX_ACCELERATION`、仿真空间大小与边界回中权重。

## 算法要点

每个仿真步中，对每个个体统计其邻居并计算期望加速度：

- **分离（separation）**：对分离半径内的近邻施加排斥，距离越近权重越大，用于避免碰撞；
- **对齐（alignment）**：使速度方向趋近邻居平均速度，用于速度一致；
- **聚合（cohesion）**：朝邻居平均位置靠拢，用于形成并保持队形；
- **边界回中**：接近仿真空间边界时施加指向中心的转向，避免集群飞出研究区域；
- **运动约束**：加速度先限制在 `MAX_ACCELERATION` 内，更新速度后再限制在 `MAX_SPEED` 内；
- **积分**：采用半隐式欧拉法更新速度与位置。

三条规则的权重是相互竞争的关系，调大分离权重会增大个体间距，调大聚合权重则会让队形更紧凑。

## 输出统计的含义

| 统计量 | 含义 | 用途 |
| --- | --- | --- |
| 平均位置 | 集群质心 | 观察编队整体漂移与收敛趋势 |
| 平均速度 | 集群平均速度向量 | 判断速度一致性、是否形成共同运动方向 |
| 平均最近邻距离 | 每个个体到最近邻距离的平均值 | 衡量集群疏密与最小安全间距是否被破坏 |

## 与无人机集群控制研究的对应关系

这个示例虽然只使用点质量模型，但保留了集群控制研究中最核心的「局部规则 → 全局编队」闭环，可作为理解下列问题的入口：

- **碰撞避免与安全间距**：分离规则对应无人机之间的最小安全距离约束，平均最近邻距离可作为初步的安全指标。
- **一致性协议**：对齐规则是速度一致性（consensus）的最简形式，可继续扩展为基于通信拓扑的分布式一致性协议。
- **编队保持与队形生成**：聚合规则对应队形保持；后续可加入虚拟结构、领航—跟随或基于图论的编队控制，使集群收敛到指定几何队形。
- **执行器与动力学约束**：最大速度、最大加速度对应真实多旋翼的推力、姿态与能耗限制；进一步可接入六自由度动力学与姿态控制器。
- **通信与感知约束**：当前假设个体可获知邻居的完整状态，后续可加入通信半径、拓扑变化、时延与丢包。
- **可扩展性与鲁棒性**：可研究个体数量增长时的计算与通信开销，以及个体失效后的队形重构。
- **地理围栏与安全**：边界回中相当于简化的地理围栏，可扩展为更严格的禁飞区与返航逻辑。

## 已知局限与后续方向

当前实现是**三维点质量、双积分器模型**，不包含姿态动力学、气动、障碍物、通信时延与任务分配。若要与真实无人机系统衔接，可按以下顺序扩展：

1. 引入通信拓扑与邻居选择策略，研究拓扑对编队收敛的影响；
2. 加入静态 / 动态障碍物与局部避障算法；
3. 加入领航者、虚拟结构或基于图论的编队控制，实现指定队形；
4. 将点质量模型替换为多旋翼动力学与姿态控制，接入 PX4 SITL / ROS 2 仿真；
5. 在统计量之外记录轨迹与队形误差曲线，形成可复现的实验基线。
